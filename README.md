# SSC AI Prep UI V3

This version changes the UI so the uploaded study material is the MAIN reading area and the Chat Assistant stays at the BOTTOM.

Flow:
1. Upload PDF / DOCX / HTML / image / TXT / MD.
2. Read the extracted material in the large Reader area.
3. Use Summary, Key Points, Practice, Mock Test, Analysis and Preview from the sidebar.
4. Return to Reader whenever you want.
5. Ask questions using the Chat Assistant fixed at the bottom.

Mock Test supports:
- 5, 10, 20, 30, 50 questions
- 5, 10, 20, 30, 45, 60, 90 minutes
- marking schemes
- countdown
- previous/next/skip
- result and accuracy

No Python backend is required. External browser libraries are loaded from CDNs.

This is a local browser AI-style implementation, not the actual ChatGPT model.
